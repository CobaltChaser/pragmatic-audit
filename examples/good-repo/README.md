# Tasks demo

A deliberately small, well-factored example used by the pragmatic-audit tests.

## Install

```bash
python3 -m pip install -e .
```

## Usage

```bash
python3 -m tasks add "write the report"
python3 -m tasks list
```

## Test

```bash
python3 -m unittest discover -s tests
```
